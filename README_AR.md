# هدية Half-Life 💛 — ملفات المشروع

## الملفات اللي في الـ zip
- `overlay/java/.../GiftLauncherActivity.java` : شاشة الهدية (اسم المصمم + الرسائل + صلاحية الملفات + فتح اللعبة)
- `tools/patch_manifest.py` : يخلي شاشة الهدية هي الأيقونة الرئيسية ويضيف الصلاحيات
- `apply.sh` : ينزل محرك Xash3D FWGS، يضيف ملفاتنا، يبني الـ APK
- `.github/workflows/build.yml` : يبني الـ APK على GitHub من غير ما تحتاج جهاز قوي

## ازاي بيدعم أحدث أندرويد
- بيطلب صلاحية "الوصول لكل الملفات" في أندرويد 11 وأعلى (ده سبب مشاكل كتير مع المحاكيات القديمة).
- البناء بـ NDK 28 وtarget SDK 35، فمكتبات اللعبة بتبقى متوافقة مع أجهزة الـ 16KB page size.
- ده بيتحقق فعلاً لما نبني ونجرب، أنا لسه مجربتوش على تليفون.

## ملاحظة مهمة
الزراير والدراع والشفافية جاية من المحرك نفسه (Touch Options جوه اللعبة). لو لقينا إنها مش مظبوطة بعد أول بناء نعدلها في خطوة تانية.

## خطوات البناء (الأسهل: GitHub)
1. اعمل حساب على github.com واعمل Repository جديد (Private).
2. ارفع محتوى الـ zip بعد فكه (من المتصفح: Add file > Upload files).
3. روح تبويب **Actions** > **Build APK** > **Run workflow**.
4. بعد ~15 دقيقة نزّل الـ APK من **Artifacts**.
5. لو حصل خطأ ابعتلي نص الخطأ وأصلحه معاك.

## البناء من Termux (أصعب)
Termux مش مناسب لبناء أندرويد (محتاج NDK وSDK وذاكرة كبيرة). الأفضل GitHub. لو مصمم على Termux قولي ونمشي خطوة خطوة.

## ملفات اللعبة
- لازم تكون معاها نسخة اللعبة الأصلية. ما ينفعش نحط ملفاتها جوه التطبيق.
- فولدر **valve** يتحط في `/storage/emulated/0/xash/valve`
- التطبيق يفتح اللعبة على طول لما يلاقيه.
